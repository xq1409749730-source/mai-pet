# 麻衣桌宠（Mai Pet）

樱岛麻衣 Q 版桌宠 —— 一个透明的、会说话的、接了大模型的桌面小可爱。

> 高冷傲娇学姐，叫你「后辈」。

## 功能

- **透明置顶悬浮窗**：可点击、可拖拽、记住位置，窗口自动贴合形象大小
- **用自己的图片当形象**：把图片放进程序旁的「形象」文件夹即自动生效（支持 PNG/JPG/GIF/WebP，推荐透明底）
- **AI 对话**：双击她或右键菜单打开聊天框，接 DeepSeek 大模型自由聊天
- **AI 自动说话**：点击她、CPU/内存占用高、电脑空闲、识别当前任务（写代码/看视频/打游戏等）、健康提醒，全部由 AI 现场发挥（可关闭，回退内置台词）
- **系统原生右键菜单**：形象大小、选择形象、健康提醒开关、AI 开关、开机自启、创建桌面快捷方式等
- **绿色免安装**：数据保存在程序旁边，不写 C 盘（开机自启/桌面快捷方式需手动开启，会写入 C 盘）

## 快速开始（源码运行）

需要 Node.js >= 22：

```bash
npm install
npm start
```

## 打包为绿色便携版

```bash
node pack.js
# 输出在 dist/麻衣桌宠-win32-x64/
```

> 直接下载运行：见右侧 Releases 的 **`mai-pet-portable.zip`**（绿色便携版，解压后双击 `麻衣桌宠.exe` 即可）。

## 配置 AI（可选）

桌宠运行后会在程序旁创建 `麻衣桌宠-数据/` 文件夹，在其中新建 `llm-config.json`：

```json
{
  "provider": "deepseek",
  "baseURL": "https://api.deepseek.com",
  "apiKey": "sk-你的密钥",
  "model": "deepseek-chat"
}
```

- 任何 OpenAI 兼容接口都能用（改 baseURL / model 即可）
- 密钥只存在本地，不会上传
- 不配置时 AI 自动回退到内置台词库，桌宠照常工作

## 形象图片

把图片放进程序旁的「形象」文件夹：
- 支持 PNG / JPG / GIF / WebP
- 推荐透明背景 PNG，命名 `character.png` 会优先使用
- 放多张时可在右键菜单「选择形象」里切换
