# 麻衣桌宠 2.0（Mai Pet 2.0 · 关系与记忆版）

樱岛麻衣 2.0 桌宠 —— 一个会记住你、会成长的桌面小可爱。

> 高冷傲娇学姐，叫你「后辈」。

## 2.0 新增

- **三层记忆系统**：基础记忆（称呼/偏好/重要日期）+ 近期记忆（30 天自动过期）+ 长期经历（纪念册），右键「记忆管理」可查看/编辑/清空
- **亲密度与关系阶段**：每日见面、连续陪伴、重要日子、用心聊天积累亲密度（本地规则计算，AI 无权修改）；5 个关系阶段（初识→熟悉→值得关心→特别→重要之人）；升级解锁纪念册条目；可隐藏数值只显阶段
- **情绪状态机**：程序根据事件计算情绪（平静/开心/害羞/担心/不满/疲倦），AI 只负责组织台词，人格稳定
- **三档主动模式**：安静 / 日常 / 活跃（AI 频率、小动作、搭话全面联动）+ 「勿扰至…」30分钟/1小时/明天
- **AI 调用限制**：每日预算（自动说话 40 次 / 聊天 100 次）、近期记忆注入上下文、仅手动聊天开关
- **互动形象自动切换**：按状态自动换图（点击/拖拽/说话/思考/空闲/问候/喝水/庆祝/偷笑/提醒/生气等）

## 基础功能

- **透明置顶悬浮窗**：可点击、可拖拽、记住位置，窗口自动贴合形象大小
- **用自己的图片当形象**：把图片放进程序旁的「形象」文件夹即自动生效（支持 PNG/JPG/GIF/WebP，推荐透明底）
- **AI 对话**：右键菜单打开聊天框，接 DeepSeek 大模型自由聊天（含记忆上下文）
- **系统原生右键菜单**：主动程度、勿扰、记忆管理、关系、AI、形象大小、健康提醒、开机自启、桌面快捷方式等
- **绿色免安装**：数据保存在程序旁边（不写 C 盘；开机自启/桌面快捷方式需手动开启，会写入 C 盘）

## 快速开始（源码运行）

需要 Node.js >= 22：

```bash
npm install
npm start
```

## 配置 AI（可选）

桌宠运行后会在程序旁创建 `麻衣桌宠-数据/` 文件夹，在其中新建 `llm-config.json`：

```json
{
  "provider": "deepseek",
  "baseURL": "https://api.deepseek.com",
  "apiKey": "sk-你的密钥",
  "model": "deepseek-chat"
}
```

- 任何 OpenAI 兼容接口都能用（改 baseURL / model 即可）
- 密钥只存在本地，不会上传
- 不配置时 AI 自动回退到内置台词库，桌宠照常工作

## 形象图片（互动自动切换）

把图片放进程序旁的「形象」文件夹（PNG / JPG / GIF / WebP，推荐透明背景）：

- **自动按状态切换**（按文件名关键词匹配）：
  - 抱着书（默认待机）· 害羞（点击）· 盯着（拖拽）· 递便签（说话）
  - 思考（AI 思考中）· 困倦（电脑空闲）· 挥手（问候）· 捧杯子（喝水提醒）· 庆祝（开心反应）
- 没有对应图片的状态自动回退到默认形象
- 全部图片建议同一尺寸（如 1280×1519），切换更平滑
